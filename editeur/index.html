Sélection

Rien de sélectionné.
Outil Sélection (V) puis clic sur un objet.

Raccourcis

Glisser : dessiner avec l'outil
Clic droit : supprimer sous la souris
Molette : monter / descendre
Ctrl + molette : zoom
Ctrl + glisser, Espace + glisser ou clic molette : déplacer la vue
Alt pendant un glisser : ignorer l'aimant des objets
Suppr : supprimer la sélection
Ctrl+C / Ctrl+X / Ctrl+V : copier / couper / coller sous la souris
Ctrl+D : dupliquer
B : bloc gris ⇄ portail
Flèches : déplacer (Maj = ×4)
Ctrl+Z / Ctrl+Y : annuler / refaire
Bords d'un objet sélectionné : redimensionner

Rappels physique

Saut : ~49 px de haut, ~126 px de long en courant.
Joueur : 16×16.
Portail : surface bleu clair d'au moins 28 px.
Grille : on passe à travers par dessous.
1 m affiché en jeu = 8 px.
