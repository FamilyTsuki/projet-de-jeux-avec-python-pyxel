fais pour m'antrainer pour une nuit du code 
le projet est un jeux de portaille dynamique.

## Lancer le jeu

```bash
./run.sh
```

ou avec l'environnement virtuel :

```bash
.venv/bin/python jeux_1_5.py
```

## Commandes

- **Déplacement** : `Q` / `D` (ou `A` / `D` ou `Flèches gauche / droite`)
- **Saut** : `Z` (ou `W`, `Flèche haut`, `Espace`)
- **Portail 1 (Bleu)** : Clic gauche de la souris
- **Portail 2 (Orange)** : Clic droit de la souris
- **Réapparaître** : `R`
- **Afficher / Masquer l'aide** : `H`
- **Quitter** : `Échap`
